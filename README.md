# road_intersection — SDL2 + Rust

Визуальная симуляция регулируемого перекрёстка по заданию
[01-edu road_intersection](https://github.com/01-edu/public/tree/master/subjects/road_intersection).

## Управление

- `↑` — машина с юга;
- `↓` — машина с севера;
- `←` — машина с востока;
- `→` — машина с запада;
- `r` — машина со случайного направления;
- `Esc` — выход.

Системный autorepeat игнорируется. Повторный спавн также отклоняется, пока у
стартовой точки нет полного расстояния `CAR_LEN + GAP`, или если очередь
достигла рассчитанной вместимости полосы.

## Маршруты и цвета

- сиреневый — прямо;
- янтарный — налево;
- бирюзовый — направо.

Выбранный при спавне маршрут неизменяем. Та же легенда постоянно отображается
в HUD.

## Логика симуляции

У машины есть явная фаза:

```text
Approaching -> Waiting -> Crossing -> Leaving
```

Все машины движутся с одной фиксированной скоростью. Красный свет может
остановить машину только до въезда; после начала `Crossing` сигнал на неё не
влияет. Машины одного въезда соблюдают `CAR_LEN + GAP`, а после физического
расхождения разных маршрутов следуют независимо.

Светофоры используют консервативную схему:

```text
один зелёный въезд -> all-red -> следующий зелёный въезд
```

Контроллер учитывает минимальное и максимальное время зелёного, заполнение
полосы, длину и время ожидания очереди. Критические очереди приоритетны, затем
выбирается дольше всех ожидающее направление; равенство разрешается
round-robin. `all-red` завершается только после минимальной паузы и полного
освобождения конфликтной зоны предыдущим потоком.

Вместимость рассчитывается по формуле задания:

```text
capacity = floor(lane_length / (CAR_LEN + GAP))
```

## Сборка и запуск

Нужен установленный Rust toolchain.

На Windows x64 необходимые официальные `SDL2.dll` и `SDL2.lib` уже лежат в
`vendor/sdl2`; `build.rs` подключает и копирует их автоматически. На
Linux/macOS нужен только системный SDL2:

```bash
# Debian/Ubuntu
sudo apt install libsdl2-dev

# macOS
brew install sdl2
```

Запуск:

```bash
cargo run --release
```

HUD использует включённый в репозиторий `assets/font.ttf` (Roboto, SIL OFL
1.1). Внешние SDL2_ttf и SDL2_gfx не нужны.

## Проверка

```bash
cargo fmt -- --check
cargo test
```

Тесты проверяют красный/зелёный сигнал, безопасную дистанцию, антиспам,
неизменяемость маршрута, capacity, очистку конфликтной зоны, отсутствие
starvation и учёт покинувших экран машин. Headless stress-тест выполняет 60
секунд модельного времени со случайными спавнами со всех направлений и
проверяет отсутствие столкновений и переполнения полос.

## Структура

```text
src/
├── main.rs       SDL2, ввод, fixed-timestep loop
├── geometry.rs   геометрия, Path, conflict entry/exit, capacity
├── vehicle.rs    VehiclePhase, Vehicle, Sim, спавн и движение
├── lights.rs     адаптивный справедливый контроллер
├── render.rs     пассивная отрисовка сцены и HUD
├── sprites.rs    готовые текстуры машин по маршрутам
└── drawing.rs    примитивы поверх core SDL2
```
